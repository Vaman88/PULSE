These are older research branches and standalone diagnostics. The active
site imports code from `backend/` and `model/prototype2/`, not this
directory. Several archived scripts refer to research data, modules, or
service paths that were not present in the server tree copied here. Treat
them as source records rather than ready-to-run app components.

| Path | Contents |
| --- | --- |
| `root/` | Older database inspection and maintenance scripts. |
| `pt1_prototype1_original/legacy_weekly/` | Original weekly risk and demand training branch with saved artifacts. |
| `openrouter_fact_extraction_pilot/` | Archived candidate fact extraction code and sample files. |
| `test/` | Synthetic-signal diagnostics, plotting scripts, and generated artifacts. |
| `FILE_NETWORK.md` | Map of historical dependencies and the current local path. |

The `data/` and `backend/data/` directories were excluded from the local
copy. See [../README.md](../README.md) for the complete current file map.
