# Pulse inventory

Extend the incumbent Pulse palette and typography; follow the user-selected Square inventory table for task structure.

- Mode: Operate. Search and stock filtering above a compact, horizontally scrollable table.
- Fonts: existing DM Sans for controls and rows; Manrope for headings.
- Tokens: paper #f3f8f9, ink #111715, muted #5b6968, line #ced9d8, teal #286c73, white #fff.
- Table: 13px text, 11px column headings, 17px by 16px cell padding; medicine labels 14px semibold. Right-align quantities.
- Status uses visible text with green, amber, red, or neutral backgrounds; color is supplementary.
- Controls have 44px primary targets and visible teal keyboard focus. Forms use native labels and validation.
- Editing is an inline side panel, stacked above the list below 1050px. Filters wrap below 760px; the table scrolls inside its own labeled region.
- Data comes from the signed-in account. No demonstration medicines are inserted into real inventory.
